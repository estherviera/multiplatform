# Seguridad

El backend actual carece de autenticación y está pensado para desarrollo local. La seguridad de los datos locales y de sesión requiere revisión al implementar cuentas reales. Para funcionalidades nuevas define controles de acceso en servidor, validación, almacenamiento de credenciales, manejo de datos personales y registros sin secretos. Mantén los secretos fuera del repositorio.
